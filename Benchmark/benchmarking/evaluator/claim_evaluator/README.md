# Claim evaluator (planned)

For the `article-placeholders` setting, where the agent decides what each figure shows, row-level agreement with
OWID's design choices (which countries, which encoding) is the wrong criterion. This evaluator will check whether
the returned data supports each quantitative statement in the article (for example "64 countries had passed peak
population in 2026"), with statements and targets curated per article.

Not implemented yet: claim extraction and targets must first be written and reviewed for the first article.
